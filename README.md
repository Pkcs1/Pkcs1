I'm building my foundations in Python and version control (Git/GitHub) with a clear long-term direction: **AI/MLOps engineering**, focused on how machine learning models actually get built, tracked, and shipped to production — not just trained in a notebook.

I'm also working toward transferring to **Dublin City University (BSc Computer Science)** to deepen this path internationally.
